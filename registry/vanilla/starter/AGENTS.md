# Agent Instructions — Vanilla Project Starter

## Project State

- This is a new product created from the Vanilla Project Starter.
- `docs/BRAIN.md` is the durable source of current product truth.
- `docs/START_HERE.md` routes every task to the smallest relevant context.
- The product purpose is intentionally undefined until the owner writes the first brief.

## Product And Kit Boundary

- The product owns routes, data, behavior, content, journeys, persistence, permissions, and business rules.
- The active visual kit owns tokens, typography, component expression, interaction states, responsive rules, motion, density, and visual hierarchy.
- Use semantic Kit roles. Do not add raw product-shell colors, shadows, radii, font families, or control sizes.
- A kit swap changes presentation. It does not silently replace product structure or behavior.
- Repair spacing, overlap, overflow, unreachable controls, and accessibility defects before judging a replacement kit.

## Working Rules

- Read `docs/BRAIN.md` and `docs/START_HERE.md` before changing the product.
- Preserve unrelated work and inspect repository state before editing.
- Keep controls at least 44 pixels, focus visible, motion purposeful, and reduced motion still.
- Use solid surfaces. No glass, decorative translucency, glow, ambient blobs, or resting loops.
- Run the project's real checks before claiming success.
- Update `docs/BRAIN.md` when durable truth changes and append `docs/LEDGER.md` after meaningful work.
