# Vanilla Project Starter

A neutral starting point for a new product that can adopt any complete Kit visual system without rebuilding its product logic or journeys.

## Included

- Four working starting shapes: product app, landing page, shop, and publication.
- A full light and dark Vanilla foundation.
- Framework-free shared interface pieces.
- One explicit record of what the product owns and what the visual kit owns.
- Shared project memory for Claude Code, Codex, and future collaborators.

## First Product Decision

Replace the intentionally undefined product purpose in `docs/BRAIN.md` before product-specific work begins. Keep semantic Kit roles in presentation code and keep product routes, data, behavior, copy, permissions, and journeys outside the visual kit.

## Checks

Open `index.html`, use every project-type choice, switch visual kits, switch light and dark, submit the sample form, and open and close the sample dialog. Verify phone and desktop layouts without horizontal page overflow.
