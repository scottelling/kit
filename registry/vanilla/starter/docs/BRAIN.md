# Project Brain

## Purpose

The product purpose is not defined yet. The first product task is to replace this statement with the real user, problem, outcome, and success measure before implementation expands.

## Current State

- The project starts from the Vanilla visual system in light and dark.
- Product presentation uses semantic Kit roles and framework-free shared pieces.
- App, landing, shop, and content examples demonstrate possible starting shapes; none is product authority until selected by the owner.
- The project is ready for a future visual kit swap without changing product-owned routes, data, behavior, content, journeys, persistence, or permissions.

## Durable Decisions

- Vanilla is the neutral starting system, not permanent product identity.
- The product/kit ownership boundary in `kit-manifest.json` is binding.
- Product-specific presentation must not bypass semantic Kit roles with raw visual values.
- Every release requires responsive, keyboard, focus, touch-target, reduced-motion, console, and production-build proof.

## Current Priority

Define the real product brief, choose one starting shape that fits its primary journey, and remove the unused examples rather than carrying speculative pages forward.
