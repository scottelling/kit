# Direct Creative Labs

Treat brand, type, color, text, and motion as one operating system. Decisions must survive real content, interaction states, light and dark contexts, and small screens.

## Work in this order

1. Read the current design authority, brand materials, licenses, and product surfaces. Preserve locked values and identify actual gaps.
2. Record the desired traits, voice range, audience, use context, accessibility needs, and what the direction must never become.
3. If the direction is open, create three clearly different systems. Vary hierarchy, type roles, color relationships, text behavior, and interaction rhythm—not only accents.
4. Select or confirm one direction, then define:
   - two to four working brand traits and a concrete voice range;
   - display, body, and optional outlier type roles with provenance and fallbacks;
   - OKLCH roles for paper, ink, action, supporting planes, borders, focus, success, warning, and danger;
   - one repeatable text treatment that stays legible and works without image effects;
   - a small motion vocabulary for press, state change, reveal, and dialog behavior;
   - a reduced-motion equivalent for every spatial transition;
   - one recognizable structural signature.
5. Apply the system to representative product, content, form, data, and transactional surfaces.
6. Test real long copy, empty values, errors, selections, disabled controls, dark and light modes, narrow screens, keyboard use, and motion interruption.

## Refusal list

- No unlicensed or untraceable fonts.
- No color roles that depend on hue alone.
- No illegible display tricks, gradient text, glow, glass, ambient blobs, or decorative transparency.
- No motion without a state, spatial, or feedback purpose.
- No resting loops, forced page reveals, or animation that delays the next action.
- No one-off styling that cannot be expressed as a reusable rule.

Deliver the chosen system, the alternatives when requested, applied specimens, and the rules needed to keep future work coherent.
